# Project Struktur Data PHP

## Deskripsi

Project ini dibuat untuk mengimplementasikan tiga jenis struktur data menggunakan PHP, yaitu Linear Array, Linked List, dan Stack.

Project ini juga dibuat secara interaktif sehingga pengguna dapat menambahkan, menghapus, dan mengelola data pada masing-masing struktur data.

## Struktur Data yang Digunakan

### 1. Linear Array
